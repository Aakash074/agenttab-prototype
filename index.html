AgentTab prototype: state before BCH BLAZE 2026

This is what existed before the hackathon began (Nov 14, 2026 14:00 UTC), built unchanged from commit 631e586 (Nov 13, 19:28 UTC). No hosted demo existed at the time; this page was published on Nov 22 so judges can see the starting point.

  • The web app at 631e586: only the default Vite + React starter page. No wallet flow or UI had been built.
  • The covenant at 631e586 (AgentChannel.cash): a voucher micropayment channel.
  • Its 5 security tests, run on a local mock (no chain): overclaim, forged voucher, cross-channel voucher, owner shortchanged, valid settle.

Everything else (the AgentTab covenant with outpoint-bound vouchers and refund, the x402 paywall server, the MCP server, the web app, chipnet and mainnet runs) was built during the hackathon in github.com/Aakash074/agenttab.
